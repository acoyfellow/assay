Run many agents on one goal. Grade each one with a check it cannot see.

Assay keeps one receipt and one grade per agent, and computes the score from them. Change one thing, run again, and see if the score moved.

Four rules

  • The plan is frozen. Each receipt names its plan.
  • The budget is hard. A seat starts only if its worst-case cost still fits.
  • The grader is hidden. Each seat is graded once, after it stops.
  • The score is recomputed from receipts and grades.
