Spin up a fleet of coding agents.

Write a plan, run one command. Each agent gets its own copy of your repo and can only write the files you allow. When it stops, a test it never saw checks the work.

How it works

  1. Write a plan: a repo, a model, and a list of tasks.
  2. Set a budget. Each agent starts only if its worst-case cost still fits.
  3. When an agent stops, assay runs your grade command in its copy.
  4. Read one receipt per agent: what it did, what it cost, and whether it passed.
